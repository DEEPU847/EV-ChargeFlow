# ⚡ EV ChargeFlow — DAA Hackathon

A smart web prototype for EV charging slot scheduling using Data Structures and Algorithms.

## Included
- Flask backend
- HTML/CSS/JavaScript dashboard
- Priority Queue scheduling
- Greedy slot selection
- Job/deadline verification
- Add EV charging requests
- Live animated EV
- Hyderabad interactive map and charging-station markers
- Charging progress and decision log
- Project report and hackathon PPT

## Run locally

1. Open this folder in VS Code.
2. Open Terminal.
3. Run:

```bash
pip install -r requirements.txt
python app.py
```

4. Open `http://127.0.0.1:5000`.

## GitHub upload

Create an empty GitHub repository named `EV-ChargeFlow`, then run:

```bash
git init
git add .
git commit -m "EV ChargeFlow DAA Hackathon Project"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/EV-ChargeFlow.git
git push -u origin main
```

Replace `YOUR-USERNAME` with your GitHub username.
